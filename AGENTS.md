## TP AIDLC Harness (antigravity)

- Package root: `.tp-aidlc/package` (tool: `python -B .tp-aidlc/package/tools/tp.py`).
- Entrypoint: `Start TP AIDLC` (or run `python -B .tp-aidlc/package/tools/tp.py start --new --target antigravity`).
- Before starting, read `.tp-aidlc/package/rules/tp-aidlc.md` and
  `.tp-aidlc/package/skills/tp-aidlc-start/SKILL.md`.
- Do not read, edit or clone `tools/`; use `tp help`, `tp usage`,
  `tp describe <command>`, `tp doctor` and `tp manifest`.
- Baseline is normative and complete under `.tp-aidlc/package/baseline/`; never replace it
  with a summary.
- Chat is the decision surface; gates are advisory by default and no stage auto-proceeds.
